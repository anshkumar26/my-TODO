# 📝 My TODO App

A simple and responsive **TODO list** application built using **React + Vite**. It allows users to add and delete tasks with real-time feedback using **React Toastify**.

### 🔗 Live Demo  
[👉 Click here to view the app](https://my-todo-murex-five.vercel.app/)

---

## 🚀 Features

- ✅ Add and remove tasks
- 🎉 Instant feedback using toast notifications
- 💻 Clean and responsive UI (Tailwind CSS)
- ⚡ Built with Vite for fast development
